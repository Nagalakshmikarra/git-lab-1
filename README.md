# Git Lab 1

A simple webpage (`index.html`) pushed to GitHub using Git commands.

## About
This project is part of the GitHub Lab Experiment 1. It shows the complete Git workflow:
create file → git init → git add → git commit → create GitHub repo → connect remote → git push.

## Commands Used
```bash
git init
git add index.html
git commit -m "Add index.html"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/git-lab-1.git
git push -u origin main
```

## How to View
Open `index.html` in any web browser.
